# Narrative Architect

A standalone Streamlit editorial planning workbench for turning supplied interviews and research notes into a structured B2B story plan.

## What it demonstrates
- Source-first journalistic hooks and an early nut graf
- Inverted-pyramid planning and editorial prioritization
- Explicit reporting gaps, attribution and counterargument checks
- An executive byline / reported article / research feature assignment interface

**Important:** This deterministic prototype does not claim to generate or fact-check original reporting. It never invents quotations, evidence or source citations.

## Run
```bash
pip install streamlit
streamlit run projects/narrative-architect/app.py
```

Use synthetic or non-confidential source notes for demonstrations.
